Void SuperCode

A lightweight code editor

Getting Started

Click the Open File button in the sidebar to open a single file
Click the Open Folder button to browse a project folder
Click the New File button to create a new file

Tips

Press Ctrl+S / Cmd+S to save the current file
Click the Files icon on the far left to toggle the explorer
Double-click a file in the explorer to create a new file next to it
